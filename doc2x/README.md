
## 解析概述
本项目的 PDF 到 Markdown 再到 JSON 的组装解析链路，**专门基于 Doc2X 的解析规则进行设计与适配**，用于实现学术PDF文档的文本、公式、特殊符号、图表信息的提取与结构化输出。

## 依赖说明
当前流水线核心解析能力依赖 Doc2X API，本项目并未内置PDF原生解析引擎。
我们也注意到市面上存在 Manus 等开源PDF解析方案，开源方案的优势在于可以省去第三方API调用费用，进一步降低项目运行成本。

但结合我们针对科研类PDF的实际测试观测：
开源解析工具在处理科学文本、复杂数学公式、专业特殊符号、上标下标、材料学/理工学科专有排版内容时，解析准确度存在明显短板，容易出现公式错乱、符号丢失、格式错位等问题，会直接影响后续转为 Markdown 以及 JSON结构化输出的质量。

综合考虑科研文档解析可靠性，**本流水线优先推荐使用 Doc2X 作为底层解析服务**。
> ⚠️ 重要说明：Doc2X 为**非开源**解析软件。

## 用户配置要求
在使用本流水线前，请用户自行完成以下准备：
1. 前往 Doc2X 官方平台注册账号；
2. 获取个人 API Key；
3. 将 API Key 配置到项目环境变量或配置文件中。

## 工作流程简述
1. 调用 Doc2X API 解析原始PDF，输出标准化 Markdown；
2. 基于本项目定制适配逻辑，对 Markdown 做清洗、格式校正；
3. 将校正后的 Markdown 组装转换为目标 JSON 结构化结果。

## 注意事项
- API 调用产生的计费由使用方自行承担，请留意 Doc2X 的调用额度与计费规则；
- 由于 Doc2X 的解析效果会跟随官方版本迭代发生变化，因而本项目也会持续迭代适应，若出现解析异常，请优先排查Doc2X返回的原始Markdown结果，如果官方解析存在较大变动也可联系 pch_sit@sina.com；
- 若替换其他PDF解析后端，需要同步调整本项目的后处理组装逻辑，否则会出现格式解析失败。

# Parsing Overview

This project's PDF-to-Markdown-to-JSON assembly and parsing pipeline is **specifically designed and adapted based on Doc2X's parsing rules**, and is used to extract and structurally output text, formulas, special symbols, figures, and tables from academic PDF documents.

## Dependency Notes

The core parsing capability of the current pipeline relies on the Doc2X API; this project does not include a native PDF parsing engine.

We are also aware of open-source PDF parsing solutions on the market, such as Manus. The advantage of open-source solutions is that they eliminate third-party API call fees, further reducing project running costs.

However, based on our actual test observations of scientific PDFs:

Open-source parsing tools show obvious shortcomings in parsing accuracy when handling scientific text, complex mathematical formulas, specialized special symbols, superscripts/subscripts, and discipline-specific typesetting in materials science/engineering fields. They are prone to issues such as garbled formulas, lost symbols, and misplaced formatting, which directly impact the quality of downstream Markdown conversion and structured JSON output.

Considering the reliability of scientific document parsing, **this pipeline recommends Doc2X as the underlying parsing service**.

> ⚠️ Important Note: Doc2X is a **non-open-source** parsing software.

## User Configuration Requirements

Before using this pipeline, users should complete the following preparations themselves:

1. Register an account on the Doc2X official platform;
2. Obtain a personal API Key;
3. Configure the API Key into the project environment variables or configuration file.

## Workflow Overview

1. Call the Doc2X API to parse the original PDF and output standardized Markdown;
2. Apply this project's customized adaptation logic to clean and correct the formatting of the Markdown;
3. Assemble and convert the corrected Markdown into the target structured JSON result.

## Notes

- Billing generated by API calls is borne by the user; please pay attention to Doc2X's call quotas and billing rules;
- Since Doc2X's parsing performance evolves with official version iterations, this project will also continuously iterate to adapt. If parsing anomalies occur, please first check the raw Markdown result returned by Doc2X. If the official parsing changes significantly, you may also contact pch_sit@sina.com;
- If you replace the PDF parsing backend with another solution, you need to synchronously adjust this project's post-processing assembly logic; otherwise, format parsing failures will occur.
